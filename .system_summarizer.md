# Auto-Summarization System

## How it works
- After 40 messages in a session, summarize the conversation so far
- Store summary in `memory/summaries/[session_key].md`
- On session load, check for existing summary and load that instead of full history

## Trigger
When message count reaches threshold:
1. Use sessions_history to get recent messages
2. Generate a concise summary (key decisions, topics, outcomes)
3. Save to memory/summaries/[session_key].md
4. Reset counter

## Files
- `.context_tracker.json` - tracks message count and thresholds
- `memory/summaries/` - where summaries are stored
